# Nice to Have Features


## Large

- Model (package) composition and comparison.
- Localisation/internationalisation of models.
- Ability to contain/integrate other meta-models:
    - Causal maps
    - SGBN and SBOL (design, composition, graph analysis, no simulation)

## Medium-sized

- Editing variable names in arithmetic expressions while preserving the rest of the expression text.
  Use-case: A node is renamed.
